# 造数：REPORT 记录 + MCP 逐条执行

造数写在 `http/{controller_name}/REPORT.md` 各用例「造数记录」节。

## 落盘字段

1. **造数逻辑**：下次可快速理解为何造、造何状态、依赖谁、何时可复用
2. **具体 SQL**：可执行；含校验 SQL、回滚 SQL
3. **MCP 执行记录**：成功/失败、错误原文、最终采用的 SQL（若有修正）

`seed_id00` 建议：`seed_{用例id}`。

## MCP 执行规则（步骤3.5）

1. 将 REPORT 中造数 SQL **按语句拆分**（以 `;` 分隔，忽略空段）
2. **逐条**调用 MySQL MCP `mysql_query`，禁止把多条无关语句捆成一次碰运气
3. 失败时：查表结构 / FK / 枚举码 → 修正 SQL → **写回 REPORT** → 再执行该条
4. 全部成功或明确「复用已有」后，才进入步骤4
5. MCP 拒绝写操作：停下来请用户开写权限

示例标记（写在造数节末尾）：

```markdown
- MCP 执行：成功（2026-09-23T12:00:00+08:00）；共 3 条
- 修正说明：status 由 'published' 改为 0（列类型 int）
```
